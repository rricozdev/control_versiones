# Qué es Git

Git es una herramienta de control de versiones gratuita y de código abierto. Lo instalas una vez y luego ejecutas los comandos `git` dentro de cualquier carpeta que quieras rastrear.

Una carpeta que está siendo rastreada por Git se llama **repositorio** (o repo para abreviar). Dentro de esa carpeta, Git registra instantáneas de tus archivos cada vez que guardas un punto de control.

Siempre interactúas con Git a través de la terminal:

```bash
git --version
```

Esto imprime la versión de Git instalada y confirma que Git está disponible en tu sistema. Si devuelve un error, Git no está instalado.

```txt
git version 2.43.0
```

Cada comando que aprenderás en esta sección comienza con la palabra `git`, seguido de un subcomando como `init`, `status` o `commit`.

## Cuestionario

1. ¿Qué indica el hecho de que `git --version` devuelva un error?

- Respuesta: Git no está instalado en el sistema. Si `git --version` devuelve un error, Git no está instalado o no está disponible en la ruta del sistema `(system path)`.

2. Los comandos de Git se ejecutan a través de la terminal.

- Respuesta: `True`
  Siempre interactúas con Git a través de la terminal escribiendo comandos que comienzan con `git`.

3. ¿Qué es un repositorio?

- Respuesta|: Un repositorio (o repo) es una carpeta donde Git registra instantáneas de tus archivos en cada punto de control.

4. El comando `git --version` crea un nuevo repositorio.

- Respuesta: `False`. El comando `git --version` imprime la versión de Git instalada y confirma que Git está disponible. No crea un repositorio.
