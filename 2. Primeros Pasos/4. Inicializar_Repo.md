# Inicializar un repositorio

Antes de que Git pueda rastrear una carpeta, tienes que inicializarla como un repositorio. El comando para esto es `git init`:

```bash
git init
```

Ejecuta esto una vez dentro de cualquier carpeta que quieras rastrear. Git crea una subcarpeta oculta llamada `.git/` que contiene todo el historial, la configuración y los datos internos del repositorio.

Solo necesitas ejecutar `git init` una vez por proyecto. Después de eso, la carpeta es un repositorio de Git para siempre (o hasta que elimines la carpeta `.git/`).

Git imprimirá un mensaje de confirmación similar a:

```bash
Initialized empty Git repository in /path/to/project/.git/
```

## Cuestionario

1. Necesitas ejecutar git init cada vez que quieras confirmar los cambios en un repositorio.

- Respuesta: `False`

Solo ejecutas `git init` una vez por proyecto. Después de la inicialización, la carpeta sigue siendo un repositorio de Git hasta que se elimine la carpeta `.git/`.

2. ¿Qué crea git init?

- Respuesta: Una subcarpeta oculta `.git/`

El comando `git init` crea un directorio oculto `.git/` que almacena todos los datos, el historial y la configuración del repositorio.

3. Inicializar un nuevo repositorio Git

```bash
git init
```

4. ¿Cómo puedes dejar de hacer que una carpeta sea un repositorio de Git?

- Respuesta: Eliminar la subcarpeta oculta `.git/`

La carpeta `.git/` contiene todos los datos del repositorio. Eliminarla convierte el directorio de nuevo en una carpeta normal.

5. La carpeta .git/ es visible por defecto en la mayoría de los exploradores de archivos.

- Respuesta: `False`

La carpeta `.git/` está oculta porque su nombre comienza con un punto. La mayoría de los navegadores de archivos ocultan los archivos que empiezan por punto (dotfiles) por defecto.

## Desafío

Inicializar un repositorio

- Principiante  
  Inicializa la carpeta actual como un repositorio Git, luego enumera todos los archivos (incluidos los ocultos) para que puedas ver la nueva carpeta `.git`.

Usa `ls -A` para el listado. Muestra las entradas ocultas pero omite . y ...

```bash
user/home$ git init
icializado el repositorio Git existente en /home/rricozdev/Cursos/control_versiones/.git/

user/home$ ls -A
'1. Intro'  '2. Primeros Pasos'   .git
```
