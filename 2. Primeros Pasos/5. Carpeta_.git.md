# La carpeta `.git`

La carpeta `.git` es donde Git almacena todo: cada commit, cada rama, tu configuración y los punteros al estado actual del repositorio.

Casi nunca editas nada directamente dentro de `.git`. Los comandos de Git lo modifican por ti. Pero es útil saber qué hay ahí:

```bash
ls .git
branches  config  description  HEAD  hooks  info  objects  refs

```

Verás entradas como:

- `HEAD`: un archivo pequeño que apunta a la rama actual.
- `config`: ajustes para este repositorio específico.
- `objects/`: la base de datos de todas las instantáneas y el contenido.
- `refs/`: punteros a ramas y etiquetas.

Si alguna vez eliminas la carpeta `.git`, el proyecto deja de ser un repositorio de Git. Los archivos siguen ahí, pero todo el historial desaparece.

## Cuestionario

1. ¿Qué ocurre con el historial de versiones si se elimina .git?

- Respuesta: Se pierde todo el historial.

La carpeta `.git` contiene todas las confirmaciones y el historial. Eliminarla borra todo el historial de versiones.

2. Debes editar archivos dentro de `.git` directamente con regularidad para administrar tu repositorio.

- Respuesta: `False`

Casi nunca editas nada directamente dentro de `.git`. Los comandos de Git lo modifican por ti.

3. ¿Qué contiene el archivo HEAD dentro de `.git`?

- Respuesta: Un puntero a la rama actual.

`HEAD` es un archivo pequeño que apunta a la rama que tienes actualmente seleccionada.

4. ¿Dónde almacena Git todas las instantáneas y el contenido?

- Respuesta: `objects/`

El directorio `objects/` sirve como base de datos de todas las instantáneas y el contenido del repositorio.

5. Eliminar la carpeta .git quita los archivos de tu proyecto del directorio.

- Respuesta: `False`

Al eliminar `.git`, se borra el historial del repositorio, pero los archivos de trabajo permanecen en el directorio.

## Desafío - principiante

Inicializa un nuevo repositorio en la carpeta actual y después comprueba si el archivo `HEAD` existe dentro de la carpeta `.git`.

Usa `cat .git/HEAD` para imprimir su contenido. El resultado esperado es la línea del puntero de rama `ref: refs/heads/main`.
